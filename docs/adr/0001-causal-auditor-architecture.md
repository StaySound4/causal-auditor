# ADR 0001: SCM Causal Auditor 架构升级决策（首个公开发布版本 0.9.0）

- **状态**: Accepted
- **日期**: 2026-09-10
- **决策人**: 架构团队

## 背景
现有 `causal-auditor` (v3.0) 存在七大核心缺陷：Step 0 边界判定易逃逸被架空、单轮自回归角色扮演导致确认偏误、缺乏真实工具契约导致编造虚假文献与饱和度、SCM 数学内核符号化表演无计算能力、22 种偏误排查盲区多、缺乏零假设锚点致使红队合谋、STD-21/22 报表模版在伪科学场景诱发虚假平衡。

## 决策
1. **引入四大不可违背运行铁律**：Step 0 严格边界门禁（剂量/终点/人群三要素缺失必须阻断）、零假设 $H_0: ATE=0$ 绝对优先、工具契约硬性杜绝脑补、消除模糊词量化收敛。
2. **核心深模块解耦**：
   - `CausalKernel`：实现 DAG 拓扑分析、d-分离、最小后门调整集计算与 22 种偏误全谱系自动化规则扫描。
   - `EvidenceEngine`：构建真实接缝（Web/Academic/Mock 适配器），强制双向证实与证伪检索。
   - `NullHypothesisGateway`：实现信息物理隔离的零假设独立红队对抗。
   - `RuntimeOrchestrator`：双模支持单轮强契约 Prompt 与多子代理物理隔离编排。
3. **排版标准升级为 STD-23 自适应金字塔**：针对伪科学场景降维坍缩第一档，消灭虚假平衡。

## 后果
- 必须编写强类型接口契约并补充完备的单元测试；
- 彻底斩断大模型“脑补文献”与“自我背书”途径；
- 支持在单轮对话与子代理调度两种环境下自适应无缝切换。
