# legacy/ — v3.0 实现留档

这里的文件是 **v3.0 的历史实现**，保留仅为追溯与对照，**不构成本仓库的运行入口**。

## 为什么被替换

`workflow.v3.js` 与 `pipeline_architecture.v3.md` 中的设计存在已被证实的问题（详见 `docs/adr/0002`）：

| 问题 | v3.0 做法 | v0.9.0 做法 |
| :--- | :--- | :--- |
| 阻断判定 | 子字符串匹配 `includes("Q1 -")` | 强类型 `BoundaryResult` 状态 |
| 事实检索 | 提示词要求检索但未绑定任何工具 | `EvidenceSearchProvider` 接缝 + 真实 PubMed 适配器；不可用则 `UNAVAILABLE` |
| 证据充分性 | 输出"搜索饱和度 95%" | 可核验检索元数据，明确声明非充分性评分 |
| 判定 | 隐含真/伪二值 | 五值判定，含 `INSUFFICIENT_EVIDENCE` |
| 偏误排查 | 提示词列举 4 项 | 22 项目录，每项返回命中/不适用/未知 + 依据 |
| 报告 | 强制三档金字塔对称 | 自适应，不制造虚假平衡 |
| 隔离 | 宣称"物理隔离"，实际取决于宿主 | 单轮模式明确标注"非隔离" |

## 不要做的事

- 不要把 `workflow.v3.js` 当作当前入口调用。
- 不要把 v3.0 的提示词结论当作审计依据。

当前入口见根目录 `SKILL.md`。
